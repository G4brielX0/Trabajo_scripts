# MIPS Assembly — Academic exercises

Ejercicios académicos de programación en ensamblador MIPS / Academic MIPS assembly programming exercises.

| Archivo / File | Objetivo / Purpose |
|---|---|
| `fibonacci.asm` | Generar la serie Fibonacci / Generate a Fibonacci sequence |
| `numero_mayor.asm` | Comparar tres números y mostrar el mayor / Find the largest of three numbers |
| `numero_menor.asm` | Comparar tres números y mostrar el menor / Find the smallest of three numbers |

## Uso / Usage
Abrir cada archivo por separado en un simulador MIPS compatible con sus llamadas al sistema, como MARS o QtSPIM. Ensamblar, ejecutar e introducir los valores solicitados.

Open each file separately in a MIPS simulator compatible with its system calls, such as MARS or QtSPIM. Assemble, run and enter the requested values.
